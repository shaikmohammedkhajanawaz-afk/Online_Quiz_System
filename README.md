# Online Quiz System (Java)

## 📌 Project Overview
The **Online Quiz System** is a Java-based application designed to conduct quizzes and evaluate user performance. It provides an interactive platform where users can answer multiple-choice questions, submit responses, and view their scores.

## 🚀 Features
- User-friendly quiz interface
- Multiple-choice questions (MCQs)
- Answer submission
- Automatic score calculation
- Display quiz results
- Simple and organized Java code structure

## 🛠️ Technologies Used
- **Programming Language:** Java
- **IDE:** Eclipse / IntelliJ IDEA
- **Concepts:** OOP, Classes, Objects, Methods, Conditional Statements, Loops

## ⚙️ How to Run
1. Clone this repository.
2. Open the project in Eclipse or IntelliJ IDEA.
3. Configure the Java JDK.
4. Open the Main.java file.
5. Run the application.

## 🎯 Project Objective
To develop a simple and effective quiz application using Java that helps users test their knowledge and evaluate their performance.
